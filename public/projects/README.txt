Drop project cover images here (e.g. yflc-cover.svg, proptera-cover.svg,
importique-cover.png) and reference them from src/content/projects.js via
the `cover` field, e.g. cover: "/projects/yflc-cover.png".

Recommended cover size: ~1600×1000 (16:10). Until a file exists, the site
shows a clean typographic fallback automatically — nothing breaks.
